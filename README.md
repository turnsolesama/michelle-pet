# 米雪儿桌宠

《卡拉彼丘》米雪儿的个人同人 Windows 桌宠，v0.2.2。双击包内 MichellePet.exe 即可启动，无需安装，依赖 Windows 自带的 .NET Framework 4.x。

本次修复：从墙边展开后，重新按住拖动可直接返回原侧收纳，无需绕过屏幕中间；同一次拖动也可直接收纳到对面边缘。防止展开后立即吸回的保护只针对刚离开的边缘和当前拖动。保留 v0.2.1 的正立左右贴墙姿势、封闭白底清除与稳定呼吸。

- 点击头部或身体：开心表情与文字回应；点击脚部或右键选择“轻轻跳一下”：轻跳。
- 按住角色拖动，松手落到该显示器工作区底部；透明区域可穿透。
- 右键 → 换皮肤：经典制服、甜点美梦、桃心卫士、绮星梦使。每套均有待机、开心、睡觉、左贴墙、右贴墙五个姿势。
- 右键 → 睡一会儿：坐下打盹；点击或菜单“醒来啦”唤醒。睡觉时换肤保持睡姿。
- 拖到屏幕左右边缘附近松手会收纳；也可右键 → 收纳到边缘 → 左侧贴墙探头 / 右侧贴墙探头。沿边上下拖动可调整位置，点击或向屏幕内拖动可展开。换皮肤和调整大小保持收纳侧及纵向中心，靠近角落时自动限制在工作区内。
- 右键角色或托盘：160 / 240 / 360 三档大小、暂停动画、置顶、回到右下角、退出。
- 双击托盘图标：唤回鼠标所在屏幕。重复启动保持单实例。
- 不联网，不添加开机启动，不保存个人设置。退出入口固定在右键菜单底部。

本版内嵌 16 张 AI 同人图，共 20 个姿势（每张贴墙图含左右两幅）。包含呼吸、轻跳、下落及姿势切换，尚无骨骼动画、逐帧走路和语音。台词为原创同人短句，不是游戏原台词。皮肤根据官方参考改绘为 Q 版，部分细节有简化，不是官方原始游戏资产。

本仓库首次公开同步 v0.2.2。与旧版本共用单实例锁，启动前请从旧版右键菜单退出；本地旧包继续保留。

检查情况（2026-09-17）：165 项素材、状态与位置诊断通过；另有 27 项边缘路径回归通过，覆盖三档大小、左右重新收纳、跨侧及防止立即吸回。回归针对实际打包 EXE，通过方法驱动 WinForms 消息循环，不冒充真实鼠标输入；鼠标工具重试后仍命中其他窗口，本版真实拖拽未验收。原生深浅背景截图已取得，混合 DPI、多屏和长期运行未验证。源码目录 QA.md 保留各版记录。

## 开发

在本目录运行 `./build.ps1`，输出 `releases/v0.2.2/MichellePet.exe`。基础透明窗口与外边界连通去底代码来自作者的 [codex-pet 项目](https://github.com/turnsolesama/codex-pet)，保留每帧提交 SIZE 的刷新修复。封闭空隙按 assets/skins/alpha-seeds.csv 的逐图种子清除；贴墙图使用原生 Alpha。坐标使用系统 DPI 感知；跨屏混合 DPI 尚未验证。边缘路径回归源码为 tests/EdgeRegression.cs，用 .NET Framework csc 引用 System.Drawing.dll 和 System.Windows.Forms.dll 编译后，传入待测 MichellePet.exe 的完整路径执行。

`MichellePet.exe --check <绝对目录>` 会短暂显示桌宠、检查透明图层/落地/尺寸/菜单并自动退出，诊断目录含本机桌面区域截图，请勿公开上传。

素材依据：卡拉彼丘官方账号 2023-05-20 的[米雪儿角色资料](https://www.taptap.cn/moment/409001403277640749)。官方参考图片不包含在公开源码及程序包中。角色版权归原权利人所有；本项目为个人同人创作。

皮肤参考：[甜点美梦](https://www.taptap.cn/moment/460904180710640556)、[桃心卫士](https://www.taptap.cn/moment/530466757194812405)、[绮星梦使](https://www.taptap.cn/moment/740906362053070435)。完整提示词保存在源码素材目录 assets/skins/prompts.json。
