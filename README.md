# 米雪儿桌宠 · v0.3.2

v0.3.2 新增通用打字反馈：未单独标注的字母、数字、常用符号以及退格、回车、Tab，也会触发手部敲击与无标签键区亮起。连续输入会交替敲击，不读取输入框或输入法文字，不保存按键内容。游戏键仍按对应键帽定位，通用敲击结束后可回到仍按着的游戏键。

v0.3.1 修订：手指按旋转后的键帽位置同时跟踪横纵坐标，Ctrl、Shift、空格等边缘键可完整够到。组合键优先表现最近按下的键，其余按住的键保持亮起；松开后回到仍按着的键，不再取平均位置。左右手重新按同一比例制作，鼠标右手的拇指朝内、食指和中指对应两个按钮。手掌只旋转和平移，伸手时不改变大小，前臂单独连接袖口和手腕。

右键角色或托盘 → **游戏搭子 · 经典制服**：米雪儿坐在键盘与鼠标后，左手随 W/A/S/D、Q/E/R/F、Shift、Ctrl、空格敲击，右手随鼠标移动与左右键按压。组合键可同时响应；轻按保留短暂动作，长按保持按压，松开回位。头部、身体和桌面固定，前臂/手部独立运动并配合按键亮起。这是分层 2D 动画，不是 Live2D，尚未做逐手指绑定。

右键“键鼠联动”可单独关闭输入并保留坐姿。游戏搭子可拖到屏幕工作区内任意位置，松手停留，不下落、不自动贴边；点击回应也保持位置。启动默认普通桌宠，进入游戏搭子才注册后台输入；拖动、打开菜单或暂停动画会暂时停止读取。退出模式恢复进入前的服装及普通桌宠落地行为；换肤、睡眠、手动贴墙会退出该模式。四套原有皮肤均保留，新键鼠姿势目前仅经典制服。

只在内存中维护游戏按键、鼠标状态与不含字符内容的打字动作，不保存文本、按键历史或网络上传，不拦截游戏输入。鼠标采用相对移动量；具体游戏、独占全屏和反作弊环境尚未实测，可先在窗口化或无边框窗口体验。

## 开发

在本目录运行 `./build.ps1`，输出 `releases/v0.3.2/MichellePet.exe`。基础透明窗口与外边界连通去底代码来自作者的 [codex-pet 项目](https://github.com/turnsolesama/codex-pet)，保留每帧提交 SIZE 的刷新修复。封闭空隙按 assets/skins/alpha-seeds.csv 的逐图种子清除；贴墙和搭子图使用原生 Alpha。坐标使用系统 DPI 感知。tests/EdgeRegression.cs、CompanionRegression.cs 用 .NET Framework csc 引用 System.Drawing.dll 和 System.Windows.Forms.dll 编译后，传入待测 EXE 完整路径执行；NativeInputProbe.cs 是独立空白输入验收宿主，不打包给用户。

`MichellePet.exe --check <绝对目录>` 会短暂显示桌宠、检查透明图层/落地/尺寸/菜单并自动退出，诊断目录含本机桌面区域截图，请勿公开上传。
