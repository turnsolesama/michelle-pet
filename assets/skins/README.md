# 米雪儿运行素材

四套服装：classic 经典制服、dessert 甜点美梦、heart 桃心卫士、magic 绮星梦使。

每套构建使用 idle.png、happy.png、sleep.png、wall.png。wall.png 的左右半幅分别用于左右墙边，共 16 个文件、20 个姿势。当前文件尺寸与 SHA-256 见 runtime-manifest.json；生成记录见 prompts.json、wall-prompts.json。提示词内可能引用早期制作参考，官方参考与旧抓框原图未包含在公开源码中，不影响构建。

全身及睡姿 RGB 图片保留原样，程序清除与外边界连通的近白背景，并使用 alpha-seeds.csv 清除闭合发丝空隙。clear 为背景种子；keep 为需保持的白色衣服取样。坐标基于原始像素，替换图片后必须重新校准。不可用全局删白替代。

wall.png 是 1254×1254 RGBA 图片，直接使用其 Alpha，不对服装删白，也不将人物旋转 90 度。接触线相对完整画布宽度为 classic=.035、dessert=.024、heart=.038、magic=.030；左侧截取接触线至画布中线，右侧取对称区域，再裁透明边界。沿边目标高度为全身高度档位的 .78 倍。入场 .28 秒，结束后手部与窗口固定。
